# Backend

Backend dự kiến dùng Express, TypeScript, TypeORM, PostgreSQL và MinIO. API sở hữu phiên, quyền, metadata, quota và vòng đời tệp.

- [Hợp đồng API](../docs/contracts/README.md)
- [Use case](../docs/use-cases.md) và [cách kiểm chứng](../docs/verification.md)

Thư mục đang ở giai đoạn tài liệu. Bổ sung lệnh cài, migrate, chạy và kiểm thử khi khởi tạo service.
